# HUD Controller v90.35.3.24.35 — Automatic Map Mode Readiness + Native HUD Startup Message + Simplified Vehicle OBD

## Scope / compatibility
- Full iOS 26 GitHub repository based on v90.35.3.24.34, retains previous CI FIX 1 and Apple Siri metadata FIX 2.
- Paired U2W **v8.40 unchanged**. No U2W firmware flash required.
- No MapKit fallback; MainVideo decoder, sanitizer, JPEG relay, U2W sources/binaries, ETA layout, Shortcuts and vehicle speed logic remain unchanged.

## 1. Automatic Map Mode initialization
- On HUD BLE ready with saved Automatic Map Mode ON, wait 5 seconds for dashboard rehydration, then perform **read-only GET /cgi-bin/u2whud-status.cgi** at 192.168.50.2. Require local HTTP 2xx, not an iOS Internet-capable Wi-Fi path.
- If unreachable, keep stock Navigation/Free Ride and HUD OBD working. Retry with 3-second request deadlines and up to 8-second backoff, within a 90-second bounded initialization window per BLE session / explicit retry.
- When reachable, call the established /cgi-bin/u2whud-start.cgi and preserve the known-good 6→credentials→DHCP join sequence.
- HTTP start failures during automatic startup re-arm readiness checks within the *same* 90-second window. Cancel on HUD BLE disconnect, Automatic Map Mode OFF, or user-initiated credential retry.
- Transfer OBD ownership **only after a successful HTTP start acknowledgment**. Failed/unreachable startup no longer causes the iPhone to claim OBD and disrupt HUD ownership.
- Credential save or explicit Automatic Map Mode OFF→ON opens a fresh attempt; no hidden infinite retry or firmware resets.
- App status and MAP AUTO logs show failed readiness checks, connection recovery, and final timeout without exposing Wi-Fi passwords.

## 2. Stock HUD message while initializing
- Experimental **PushMessageCommandPacket** (already present in the native protocol), TOP / INFO, title `MAP MODE`. Sends `Map Mode initializing...`, `Waiting for CarPlay...`, and `Connecting Map Mode...` on *state transitions only*, plus a brief unavailable notice on timeout.
- Messages target the **existing stock Free Ride/Navigation interface before Map Mode**, not the custom Map Mode canvas. No fake Music/Spotify packet or modification of the native OBD icon.
- New `Show startup message on stock HUD` toggle in Custom Map Mode (default ON). Disable it if the experimental firmware-native message overlays important navigation content. Physical HUD behavior is not yet validated; no success is guaranteed until parked testing.
- Does not change global notification timeout, notification filters, screen mini-state, Music, or route metadata. Native messages will disappear under the HUD's own timeout policy or when its display mode changes; explicit removal is not verified.

## 3. Vehicle tab: OBD-II THROUGH HUD simplified
- Retained: Auto-connect setting, device name, Connect/Disconnect, HUD OBD ownership/status, Free Ride left/right widgets, Navigation left/right widgets, Apply buttons.
- Removed from this **screen only**: legacy OBD speed trace toggle/telemetry, supported PID forensic fields, diagnostic ZIP request/transfer/share buttons and the long experimental documentation.
- Underlying OBD capture/forensic functions remain in code (no behavior change). Separate Map Mode OBD status card remains.

## Test procedure
1. Push full repository to GitHub, run iOS CI, then run iOS 26 Ambient TestFlight and wait for processing to complete.
2. Install app, retain U2W v8.40; confirm saved adapter SSID/password and Automatic Map Mode ON. Leave `Show startup message on stock HUD` ON for a first **parked** test.
3. Fully restart car/HUD. Check for stock `MAP MODE` informational messages while waiting and for automatic display takeover once the adapter responds. Do not press Save & Retry during the first 90 seconds unless diagnosing a problem.
4. With app open or in its usual tested background state, collect app logs after parking if startup fails, noting any timeout or no native message. The stock HUD message command is experimental and may require a later parked test to validate.
5. Separately test Free Ride and Navigation widget Apply buttons; confirm HUD OBD returns when leaving Map Mode.
6. Map color distortion / initial IDR waiting are **not** changed in this release; collect U2W diagnostics on a subsequent parked collection if symptoms recur.

# v90.35.3.24.29 CI FIX 1

This package is functionally identical to v90.35.3.24.29. It fixes one Xcode 26 Swift access-control compile error reported by GitHub Actions.

## GitHub CI failure

Xcode 26.6 rejected `U2WMainVideoClient.swift` while emitting the HUDController module:

`method must be declared fileprivate because its parameter uses a private type`

`U2WMainVideoBootstrapSnapshot` is intentionally private to `U2WMainVideoClient.swift`, but `applyStartupBootstrapSnapshots(_:)` had default internal visibility. The method is only called by another type in that same file.

## Fix

The method is now declared `fileprivate`, matching its actual scope and the privacy of its parameter type.

No startup-bootstrap algorithm, background-continuity behavior, Map Mode renderer/layout logic, H.264 sanitizer behavior, or U2W payload changed.

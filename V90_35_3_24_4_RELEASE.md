# HUD Controller v90.35.3.24.4 — Center reconciliation + approaching-turn blink warning

This release is based on v90.35.3.24.3. It keeps the dual U2WH2642/U2WH2643 MainVideo handshake, U2W v8.24 firmware, and native HUD lane-renderer reset unchanged.

## Ambient fix
- A device explicitly paired as `centerConsole` is authoritative even when the legacy Center tracker still holds a stale peripheral UUID.
- Paired-Center advertisement, already-connected maintenance, and `didConnect` all replace the stale tracker and call `markPresent`.
- Positive Center evidence now reconciles an impossible `lightPresent=true` + confirmed DAY state back to NIGHT immediately.
- The existing guarded NIGHT→DAY behavior remains unchanged.

## Approaching-turn blink warning
- Custom Map Mode can blink either the maneuver arrow or the remaining-distance text.
- Defaults: enabled, Distance, below 500 ft, 3 blinks, 0.75 s between OFF/ON state changes.
- Customization range: threshold 100–2000 ft, 2–5 blinks, interval 0.5–2.0 s.
- Warning triggers once per route-maneuver index when the live distance enters the threshold.
- Blink uses opacity while preserving layout slots, so lanes/ETA/street never jump.
- A Preview blink button is available in Map Mode image customization.
- The selective blink applies to custom Map Mode pixels. Stock Navigation mode is not toggled because its firmware maneuver packet does not expose independent arrow/distance visibility.

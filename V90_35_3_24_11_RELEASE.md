# HUD Controller v90.35.3.24.11 + U2W v8.27.1 Passive MainVideo Diagnostic

This release is intentionally diagnostic-first. It restores the exact field-proven v8.11 AppleCarPlay MainVideo selector and exact v8.27 live-edge relay, and adds only a read-only adapter topology probe outside AppleCarPlay.

## Safety boundary
- No v8.28/v8.29 selector logic.
- No new AppleCarPlay preload hooks.
- No AppleCarPlay kill, signal, restart, fd close, or traffic injection.
- Full adapter power cycle is required after flashing so the running AppleCarPlay process maps the restored v8.11 shim.

## Passive source-lifecycle probe
The app starts `u2wvideo-diag-start.cgi` only after the existing Route Guidance endpoint proves the adapter is reachable. The adapter then samples every 5 seconds:
- AppleCarPlay PID and executable;
- v8.11 `main_fd`, generation, mirrored byte/write counters and NAL-looking counters;
- selected fd symlink target;
- periodic/full fd topology and relevant process mappings;
- MainVideo live-file size.

Manual snapshot captures a detailed current topology plus a bounded 512 KiB tail of the v8.11 mirror. Bundle collection after parking packages the timeline, manual snapshots, relay/exporter status, current process/socket tables, recent dmesg, and a bounded 2 MiB MainVideo tail.

## iPhone runtime
Automatic MainVideo predecode is disabled outside explicit live Map Mode. Ordinary CarPlay/Route Guidance runs without TCP/15332 or VideoToolbox load. This lets the source-lifecycle probe observe the known-safe exporter without the live-map decoder changing adapter load.

No ambient-light, lane-guidance, speed-limit, media, or HUD layout behavior is intentionally changed.

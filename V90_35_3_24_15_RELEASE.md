# HUD v90.35.3.24.15 — HUD Resync + App-Only Live Preview + Map Mode Startup Fix

Pair with the existing U2W v8.31 Navigation-Priority Raw MainVideo image.

## Scope

This is an app-only follow-up to v90.35.3.24.14. U2W v8.31 is unchanged.

### 1. Physical HUD Navigation resynchronization

A HUD firmware/session reset can return the physical unit to Freeride even while CarPlay Route Guidance remains active. v24.15 now treats physical display mode as state that must be re-established independently of logical Route Guidance ownership.

- Active Route Guidance is reasserted after HUD rehydration phase 2 and phase 3.
- Resync republishes Navigation ON, ETA, current maneuver, and live lane state.
- Navigation activation schedules a bounded pair of delayed Navigation ON recovery pulses.
- While a CarPlay route remains live, an idempotent Navigation ON assurance is rate-limited to once every 8 seconds.
- Physical Navigation ON is suppressed while physical KivicCast/Map Mode owns the HUD.

This also protects quick stop/restart cases in which Route Guidance ownership may remain held during the existing inactive-route holdover window.

### 2. App-only live MainVideo preview

A new explicit `Start Live Preview (app only)` control starts only:

- U2W v8.31 tiny raw MainVideo relay;
- iPhone H.264 parser/decoder;
- the app's existing Map Mode preview image.

It does **not** start physical HUD casting, does not send HUD mode 6, and does not alter Navigation Mode ownership. The preview is explicit/on-demand rather than automatically running for the entire drive. It stops when the app backgrounds.

If physical Map Mode is enabled while app-only preview is already healthy, the same MainVideo decoder session is reused.

### 3. Map Mode startup state-machine fix

v24.14 incorrectly classified a legitimate asynchronous TCP-connect state as `FAILED_SAFE`, so a second Map Mode attempt could be terminated in the same second that the raw relay became ready.

v24.15 removes that false failure path and separates startup into bounded stages:

1. up to 12 seconds for relay/TCP/first-byte transport readiness;
2. after transport readiness, up to 20 seconds for a fresh decoded CarPlay frame;
3. physical HUD mode 6 is entered only after a fresh frame is available.

Every physical Map Mode attempt has a generation token so a cancellation/deadline from an older attempt cannot terminate a newer attempt.

If startup fails, stock Navigation remains authoritative. If app-only preview was not explicitly requested, MainVideo is stopped. If preview was already running, only physical Map Mode is abandoned and the preview session may remain active.

## Safety boundary retained

U2W v8.31 remains unchanged:

- exact v8.11 AppleCarPlay exporter path;
- existing v8.8 Route Guidance path;
- no AppleCarPlay restart/signal;
- no adapter-side H.264 parser/cache/reference-chain spool;
- 32 KiB raw relay buffer;
- no MainVideo relay autostart;
- Navigation has no MainVideo dependency.

Unrelated production modules remain unchanged from v24.14, including ambient lighting, HUD BLE/OBD transport, Map Mode canvas/layout, and Now Playing.

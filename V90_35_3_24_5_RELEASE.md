# HUD Controller v90.35.3.24.5 — MainVideo recovery v2 + HUD FPS/OBD probes

App-only update. **U2W v8.24 is unchanged and does not need to be reflashed.**

## MainVideo recovery v2
- Each decoder-stall episode receives at most one TCP reconnect/recent-anchor reseed.
- If that bootstrap immediately fails before producing a frame, the app quarantines the replay, preserves the healthy TCP stream, and waits for a genuinely new live IDR.
- A successfully decoded frame resets the one-reseed budget.
- Actual network/socket failures still use the normal transport reconnect path.

This directly targets the 2026-09-21 drive where H.264 bytes remained fresh while VideoToolbox repeatedly returned `-8969` and the old 0.10 s reseed loop accumulated client/send churn.

## HUD frame-rate probe
- Selectable 5 / 8 / 10 / 12 / 15 fps target.
- Default remains 5 fps.
- Diagnostics show actual send fps, recent JPEG KB/s, dropped frames, and reconnect count.
- Both live U2W relay and legacy Map Mode loops follow the selected cadence.

## OBD speed probe v2
- Interprets the standard Mode-01 PID bitmap and reports whether PID `0x0D` (vehicle speed) is advertised.
- 45-second non-disruptive probe keeps GPS speed visible and does not expose the stock HUD layer.
- Refreshes hidden stock `OBD_DRIVING_VELOCITY` item 10 while collecting HUD RX frames.
- Scores integer candidate fields against simultaneous GPS mph/km/h and emits `OBD PROBE SUMMARY`.
- Diagnostic only: GPS remains the production speed source until a stable OBD field is proven.

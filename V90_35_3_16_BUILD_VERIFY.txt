MainVideo changes:
- Raw v8.17 bytes are syntax-validated on the iPhone before VideoToolbox.
- SPS must parse to exactly 800x480; PPS must reference an accepted SPS; VCL slices must reference an accepted PPS/SPS.
- False/unknown Annex-B NALs are rejected before decode.
- Fresh raw bytes with no image for 20 s trigger a local decoder resync only; the HTTP stream stays open.
- Local decoder-resync cooldown: 30 s.
- True raw-source silence: 60 s before a transport reconnect.
- Source reconnect cooldown: 60 s.
- Actual HTTP completion/error retry backoff: 5 s.
- URLSession request inactivity allowance: 60 s.
- MainVideo starts only after live U2W Map Mode successfully starts and stops immediately when live Map Mode stops.
- Normal Navigation/Freeride never starts MainVideo.
- UI exposes raw/valid/rejected SPS/PPS/IDR/slice counters.

OBD diagnostic follow-up:
- 12 s probe-end cleanup no longer clears the OBD custom slot while live Map Mode remains active.
- Fullscreen + KeepAlive restore the custom GPS-rendered Map Mode speed while the stock OBD slot stays hidden.
- One delayed health check reasserts OBD if it nevertheless drops.
- The diagnostic OBD slot is cleared when Map Mode itself exits, with one health reassert if exit cleanup disconnects OBD.
- No production OBD vehicle-speed source is enabled.

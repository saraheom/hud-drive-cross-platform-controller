# HUD Controller v90.35.3.24.23 + existing U2W v8.35 Release Notes

## Release type

**App-only corrective release. No U2W reflash is required.** Continue using the already-installed U2W v8.35 bounded-keyframe layer over the field-validated v8.34 hard-bounded mirror and exact v8.31 raw relay.

## 1. MainVideo preflight compatibility fix

The October 5 field drive showed the U2W relay was actually RUNNING and the adapter was producing valid SPS/PPS/IDR, but v24.22 never opened TCP/15332. Its preflight status parser still required the legacy `marker=YES` field. U2W v8.35 intentionally reports `v835_marker=YES` and `v834_mirror_marker=YES` instead.

v24.23 accepts any of these compatible markers:

- `marker=YES` (legacy)
- `v835_marker=YES`
- `v834_mirror_marker=YES`

A successful HTTP status, `relay_process=RUNNING`, and a supported raw-relay version remain mandatory. This fixes the false FAILED_SAFE startup without weakening the fail-closed boundary.

The existing lifecycle-aware VideoToolbox recovery and bounded keyframe-request logic are unchanged, so the next field test can finally exercise the v8.35 keyframe request instead of failing before TCP opens.

## 2. Physical lane-overlay stale-state hardening

The prior Winding Wy field case showed a stale physical HUD lane overlay after the maneuver advanced and CarPlay reported `showing=false`. v24.23 retains the existing generation-guarded Navigation-renderer recreation and adds one more delayed empty-lane command after the renderer settles.

The added clear is allowed only while:

- Navigation remains active,
- the HUD is connected,
- the lane presentation generation has not changed, and
- no new lane guidance has arrived.

A valid new lane event therefore cancels the stale-lane recovery before it can erase current guidance.

## 3. Map Mode ETA AM/PM toggle

Map Mode now has a persisted **Show AM/PM in ETA** setting.

- Default: ON
- ON: `ETA 3:54 PM`
- OFF: `ETA 3:54`

This is a display-only preference. It does not modify the Route Guidance ETA value, the stock Navigation ETA widget, or Time Left.

## 4. Clearer HUD-side OBD ownership controls

The Vehicle page now labels the stock OBD controls explicitly as:

- `Connect via HUD`
- `Disconnect HUD OBD`
- `HUD owns OBD: YES/NO`

The Direct ELM block also shows HUD ownership and HUD Auto-connect state. `HudOBDController` writes `OBD OWNERSHIP` log entries for Auto-connect changes and manual HUD connect/disconnect requests.

For a single-client ELM parked test:

1. Turn **Auto-connect OBD after HUD connects** OFF.
2. Tap **Disconnect HUD OBD**.
3. Confirm `HUD owns OBD = NO`.
4. Scan again in **Direct ELM327 Feasibility**.
5. If the adapter appears, connect and use the one-shot `01 0D` probe while parked.
6. Restore stock ownership by disconnecting Direct ELM, tapping **Connect via HUD**, then re-enabling Auto-connect if desired.

Direct ELM remains diagnostic-only. Production Map Mode speed remains GPS.

## Unchanged safety boundaries

- U2W v8.34 hard-bounded mirror: unchanged.
- Exact v8.31 32-KiB raw relay: unchanged.
- U2W v8.35 keyframe helper/CGI: unchanged.
- No AppleCarPlay or ARMiPhoneIAP2 restart/signal path.
- No MainVideo source-FD reacquisition.
- No MapKit fallback.
- Route Guidance and Now Playing paths are unchanged.
- Ambient-light behavior is unchanged.
- Production speed source remains GPS.

## First field test

1. Keep the currently installed U2W v8.35; do **not** reflash.
2. Start Google Maps + Map Mode normally without intentionally reversing.
3. Confirm MainVideo now proceeds past relay preflight and opens TCP/15332.
4. If startup lacks a usable IDR, capture whether the bounded v8.35 keyframe request is issued and whether SPS/PPS/IDR follows.
5. Observe lane behavior through maneuver transitions with no lane guidance on the next maneuver.
6. Test the ETA suffix toggle in Map Mode.
7. For the ELM single-client experiment, use the manual HUD OBD release sequence above while parked.
8. If MainVideo fails, collect the normal Live Map Diagnostic ZIP and HUD log.

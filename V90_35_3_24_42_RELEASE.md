# HUD Controller v90.35.3.24.42 — multi-tile speed-limit coverage + bold U-turn

## What was wrong in the October 27 recorded drive
The previous Current + Nav build successfully downloaded posted-speed-tagged OSM ways (41 ways in one cached area) and matched Ridge Avenue to an explicit 25 mph limit at 2.8m distance. Most of the recorded route had no sign because it was outside the tiny active cache radius and further Overpass requests failed. The next patch addresses **when and where road data is fetched, and how overlapping cached areas are activated**, without permitting the wrong expressway road identity.

## Changes

1. **Prefetch 270m ahead while moving.** Use valid GPS course at 2.5m/s or faster, otherwise query at current location. Preserve the exact original Current 400m speed-tagged Overpass query, shared URLSession networking, endpoints, and retry policy. Successful queries are each recorded at the real geographic query center, not the old GPS position.
2. **Incremental geographically indexed cache:** Collect all cached areas whose real query centers are within 385m of the current vehicle position, rather than activating only one 240m area and discarding other roads. Merge by OSM way ID, newer areas overriding duplicate IDs, keeping up to 128 distinct snapshots for 72 hours. Cache works when network refresh fails.
3. **Acquire next tile early:** Once the lookahead target is >190m from every recently downloaded query center, start acquiring the next tile (single in-flight query; never hammer public Overpass). The supplementary untagged-road request is skipped for far-ahead requests so it cannot monopolize the serial lookup while driving.
4. **Correct request/result location:** An HTTP response arriving 30–60s later updates cached data at the original *query target*, then refreshes display state from the latest live GPS location, not the stale pre-request location.
5. **Conservative identity and warnings:** Same-street CarPlay name and 20–34m true polyline corridor are still required before showing an explicit posted limit. Verify warning eligibility for the selected OSM way individually, so an overlapping but old tile cannot accidentally arm an overspeed warning. Unknown stays blank; no 'Unknown' text or guessing.
6. **U-turn icon bolder:** Increased the existing approved glyph alpha stroke/arrowhead weight in its Thin, Regular and Bold PNG variants. Original silhouette, left/right orientation, 37×40 layout, thickness setting and roundabout graphic are preserved.
7. **Includes earlier v24.41 CI FIX1:** The corrected `V9033FieldRefinementTests.swift` is included; no production logic affected by that XCTest correction.

## What has *not* changed
Original Current source's query and geometry/scoring methods, U2W v8.40 and MainVideo decoder, BLE/HUD, direct ELM OBD, HUD layout/preset persistence, roundabout dimensions and number graphics remain unchanged. No adapter firmware flashing required.

**Limitations:** Public Overpass servers or cellular data may still be unavailable. An area never downloaded has no verified limits, and some streets lack usable tagged speeds. This release does not bundle a complete offline city map or guarantee uninterrupted signs. It should improve reuse and prefetching when network downloads succeed; only the next road test can measure the real availability.

# HUD Controller v90.35.3.24.40 — Current + Nav acquisition recovery and smaller roundabout

## Why this build

The October 26 two-drive app log reported `SPEED CURRENT NAV CACHE cold start: no persisted OSM road snapshot`, repeated failures to both public Overpass endpoints, and `activeRoads=0` throughout active navigation. This left almost all speed-limit signs hidden even though local U2W CarPlay data was available. The UI showed an oversized custom roundabout compared with ordinary maneuver arrows.

## Changes

1. **Current + Nav now fetches tagged roads FIRST using the stock Current Overpass query shape:** `way[maxspeed][highway](around:400,...);out tags geom;`. The small successful response is immediately stored in the persistent OSM cache and used to resolve limits, subject to the existing CarPlay current-street identity and GPS-distance/heading safeguards. No neighboring highway limit may substitute for a mismatched street.
2. **Untagged road geometry is supplemental, not blocking.** When the CarPlay street is missing from the tagged response, an optional 160-meter `way[highway][name]` request may add nearby road geometry. Its failure does not clear or delay the already available tagged dataset. No speed value is inferred from an untagged street.
3. **Cellular-only HTTPS retry for CarPlay local-only Wi-Fi.** Ordinary `URLSession` remains first. On connectivity errors/timeouts, a bounded `Network.framework` TLS request requires the cellular interface. This is only attempted when normal networking cannot reach Overpass, and cannot work when cellular is unavailable or restricted. Errors are logged as `SPEED CURRENT NAV NETWORK` without inventing speed limits. HTTP failures are not duplicated over cellular.
4. **Shorter acquisition recovery:** primary fallback backoff starts at 20 seconds and grows exponentially to 5 minutes, rotating independent public endpoints on failure. Successful areas remain cached on disk (72 hours) with coverage expanding to 240 meters for the 400-meter tagged query.
5. **Roundabout glyph reduced:** the numbered circular route graphic is now 39 × 39 pixels rather than 61 × 59 inside the normal 80 × 58 maneuver slot. Center number and stroke sizes are scaled accordingly; there are still no small exit labels or `EXIT` text. Approved U-turn is untouched.
6. **Regression maintenance:** old Python assertions no longer hard-pin the previous app version; one source-level acquisition suite and four native XCTest HTTP response tests were added.

## Unchanged

- The original **Current** matcher, including its 400m query, original geometry scoring, and display behavior.
- Current + Nav strict CarPlay road name/OSM identity and GPS corridor gate; unknown limits remain hidden and warnings disabled.
- OBD ownership, reconnection, GPS backup, Map Mode startup, personalized presets and undo.
- MainVideo H.264 pipeline, Keep Decoder + BG Task, U2W v8.40 firmware/source, and approved U-turn graphic.

2. For the first trip, leave `Current + Nav` selected. Watch `SPEED CURRENT NAV QUERY SUCCESS primary=stock-speed-tagged` and `SPEED CURRENT NAV CACHE` logs. `SPEED CURRENT NAV NETWORK CELLULAR SUCCESS` confirms cellular fallback where needed.
3. Verify nearby expressway 50 mph is never borrowed when Google Maps identifies MLK Drive / Sweetbriar Dr. An unknown limit still hides the sign rather than displaying text.
4. Verify the custom numbered roundabout now matches normal maneuver size at the current preset scale.

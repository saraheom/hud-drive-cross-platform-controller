## Automatic Map Mode credential repair

1. Shared `HUDU2WAdapterWiFiCredentials` resolver in `ios/HUDController/App/AppState.swift` now makes auto startup, viewer rejoin/recovery, and UI honor the same SSID semantics.
2. If no SSID was ever saved, the prior UI's displayed default `NISSAN68` is also used by automatic startup. An explicitly blank SSID remains invalid; no SSID is guessed beyond this existing default.
3. A nonempty saved adapter password remains mandatory. No default password is invented or logged. If the network name or password is missing, startup is deferred with a **specific missing-field status** instead of generic silence.
4. `Save adapter Wi-Fi & retry Map Mode` in Custom Map Mode explicitly persists both visible fields and schedules a new guarded startup attempt in the **current BLE session** whenever Automatic Map Mode is ON. Dismissing the keyboard after editing either field also commits and schedules once; changing from SSID to password does not begin an early attempt mid-edit.
5. Retries continue through the existing serialized auto-start reconciler, preserving its five-second HUD dashboard rehydration delay. The saved Automatic Map Mode setting stays ON during missing-credential and Wi-Fi failures; existing healthy physical sessions are not restarted by saving settings.
6. Default settings status proactively identifies missing Wi-Fi name vs password.

## Recommended field check
1. Install this app build from a newly processed TestFlight version; leave U2W v8.40 installed.
2. In **Custom Map Mode**, confirm the actual adapter SSID and enter its password once if the app indicates it is missing. Tap **Save adapter Wi-Fi & retry Map Mode**. Do not share the password in diagnostics.
3. Set Automatic Map Mode ON. With HUD and adapter connected, verify Map Mode enables without manual toggling.
4. Shut down the car completely and reconnect on a second drive; confirm the stored ON preference starts Map Mode automatically.
5. Toggle with the iPhone Action Button Shortcut only as an optional final check. If start fails, collect the normal app/adapter diagnostics after parking.

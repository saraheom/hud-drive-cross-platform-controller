# HUD Controller v90.35.3.24.29 UI FIX 1

App-only correction on top of v90.35.3.24.29 CI FIX 2. U2W v8.38 is unchanged.

## Map Mode layout designer selector
- Replaces the nested horizontal component ScrollView with an adaptive multi-row `LazyVGrid`.
- Every Map Mode component is directly tappable; no horizontal gesture arbitration is required inside the page's vertical ScrollView.
- Selected/unselected component chips now have explicit hit targets and visual selection state.
- ETA remains absent from the selector whenever lane-position sharing is enabled.

## ETA / lane-guidance sharing
- Makes the shared renderer policy explicit through `shouldRenderETA` and `etaCanvasComponent`.
- When lane-position sharing is enabled and lane guidance is available, lane arrows render and ETA is suppressed.
- When lane guidance is unavailable, ETA renders at the exact Lane Guidance canvas coordinate.
- The same `HudMapModeCanvas` path is used by the customization preview and the physical 480x240 HUD JPEG, so both now have an explicit mutually-exclusive contract.
- Time Left remains independent.

No MainVideo, startup-bootstrap, mid-drive continuity, OBD, navigation, or U2W code is changed by this patch.

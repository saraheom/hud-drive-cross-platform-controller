Implementation safety gates
---------------------------
- Minimal native ADB transport; AUTH is rejected rather than bypassed.
- Before connection is accepted and immediately before write, device identity must be:
    ro.kivic.model=HUDWAY Drive
    ro.kivic.firmware.version=1.1.27
    ro.adb.secure=0
- Runtime write preflight requires /data/local/bootanimation to already exist and be writable.
- Selected video is converted to actual 480x240 pixels at 24 fps; renderer scale is forced to 1.0.
- Generated/imported boot animation archive limit: 100 MB.
- Imported ZIPs require STORE/no compression, matching desc.txt, and exact 480x240 PNG dimensions.
- Upload target is bootanimation.zip.pending.
- Complete ADB RECV read-back verifies byte count + SHA-256 before commit.
- Commit is same-directory mv to bootanimation.zip + chmod 0644.
- Final committed file is read back and SHA-256 verified again.
- Failure before commit removes only the pending file.
- Restore Stock removes only data/local override/pending files.
- Reboot is a separate user-confirmed action.

# HUD Controller v90.35.3.24.41 — Current + Nav request-path parity and recorded-log replay

## Purpose

Fix a proven regression in `Current + Nav` road-data acquisition without changing the plain `Current` matcher, the safety gate rejecting incorrectly named highway roads, or the existing Map Mode, OBD, firmware and video pipeline.

## Changes from v24.40

1. **Original Current transport parity.** The primary Current + Nav Overpass query now uses the same `URLSession.shared.data(from:)` semantics and conventional URLSession timeouts as the successfully tested original Current matcher. Removes the v24.40 `URLRequest.timeoutInterval = 11` cutoff. The exact speed-tagged Overpass query remains lightweight (`way[maxspeed][highway]` around 400 m). A Foundation-only `CurrentNavOSMTransport` isolates the real request path for deterministic mocked-response tests.
2. **Original endpoint first.** `https://overpass-api.de/api/interpreter` is preferred to reproduce original Current endpoint ordering. `https://overpass.private.coffee/api/interpreter` remains a backup after failed attempts. Existing cache and exponential retry backoff remain.
3. **More actionable network diagnostics.** Reports URLSession request duration, HTTP status, payload bytes, and decoded OSM-way count before any street-name decision. If a genuine connectivity failure occurs, the v24.40 cellular-only fallback remains available; non-2xx responses are not treated as valid speed data.
4. **Production road-identity replay tests.** Extracted 429 observed speed-limit decisions from `HUD_2026-10-22_12-55-02.log` (road names, times and prior decisions). An executable Swift test exercises the production street-normalization and road-geometry policy against mocked OSM JSON and simulated GPS segment locations; it rejects all 38 recorded mismatched expressway decisions. The GPS/OSM geometry used by this replay is **synthetic** because historical logs do not include every candidate polyline; it is not a complete replay of an actual live route.
5. **Version labels and test expectations.** Diagnostics identify v90.35.3.24.41; obsolete version-pinned Python regressions were updated without modifying their product expectations.

## Explicitly unchanged

- Original `Current` speed-limit matcher and associated original query method.
- `Current + Nav` safety behavior: reject incompatible street identities; unknown speed results in no speed-limit sign or overspeed warning.
- Persistent Current + Nav road snapshot cache and bounded fallback logic.
- Small 39×39 numbered roundabout graphic and the user-approved U-turn graphic.
- ELM327 OBD speed, BLE ownership and recovery; HUD Wi-Fi/automatic Map Mode; video decoder and MJPEG/H.264 relay; U2W v8.40 firmware and overlays.

## Limits of this validation

The local tests validate request construction, timeout semantics, HTTP success/error/timeout handling, source road-name guards, and synthetic GPS road geometry. They **do not** prove the live Overpass endpoints, iOS cellular interface, or Apple's full Xcode project compile/build will succeed during a drive. Road segments without trustworthy posted-speed tags must still leave the sign blank rather than borrow a nearby highway's limit.

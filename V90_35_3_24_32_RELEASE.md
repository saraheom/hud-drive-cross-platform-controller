# HUD Controller v90.35.3.24.32

Paired adapter: **U2W v8.40 Resource-Safe Bootstrap** (unchanged; no adapter reflash required from v8.40).

## Production background continuity

- Removes the selectable Background Continuity experiment controls from the normal UI.
- Production Map Mode uses **Keep decoder + BG task**.
- When iOS invalidates VideoToolbox with `kVTInvalidSessionErr (-12903)` during lock/background transition, the app automatically attempts the existing v8.40 read-only retained-history bootstrap while backgrounded.
- The existing single-flight bootstrap and cooldown remain in force, so lifecycle events cannot fan out into overlapping snapshot requests.
- If retained history cannot supply a usable IDR, normal `WAITING_FRESH_IDR` remains the safe fallback. The known Nissan Home -> CarPlay screen-switch workaround can still provoke a fresh producer IDR while the producer-side keyframe request is investigated separately.

## Map Mode owns MainVideo

- Explicit Map Mode enable is the only normal start gate for MainVideo.
- Disabling Map Mode stops MainVideo.
- The phone preview is passive and no longer starts a separate app-only MainVideo session.
- The source CarPlay map is rendered whenever Map Mode is enabled, even with no active navigation route.
- Ending navigation/arriving at the destination removes route overlays only; the live CarPlay map remains visible until Map Mode is disabled.

## ETA / lane shared position

- Fixes field behavior where ETA remained hidden after lane arrows disappeared.
- `laneGuidanceVisible` now comes from `shouldDisplayActiveLanes()`, the same custom-renderer policy that decides whether lane arrows are actually shown.
- With **ETA uses lane position when no lanes** enabled:
  - actual custom lane arrows visible -> lane arrows occupy the lane coordinate and ETA is hidden;
  - no custom lane arrows visible -> ETA occupies that exact lane coordinate.
- Cached lane vectors or a raw provider `laneGuidanceShowing` state can no longer suppress ETA by themselves.

## Turn-distance warning

- Replaces the old approach-turn blink behavior with continuous distance-text warning color.
- Adds **Turn distance warning** to the compact **Map Mode Warnings** card.
- Default threshold: **500 ft**, adjustable from 100-2000 ft in 50-ft steps.
- The maneuver distance changes to the same **Warning text color** used by the optional overspeed number-color warning.
- Speed background highlighting remains independently configurable.
- Warning uses the numeric Route Guidance maneuver distance rather than parsing display text.

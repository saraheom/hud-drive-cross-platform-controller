# v90.35.3.24.26 CI Fix 1

This is a **test-contract-only correction** for the compact production UI introduced in v90.35.3.24.26.

GitHub CI successfully built the app, but the XCTest step failed 18 source-inspection assertions across nine legacy test files. Those assertions still expected UI strings and controls intentionally retired by v24.26, including the old `Status & diagnostics` disclosure, `VideoToolbox decoder`, frame-ingress counters, Direct ELM feasibility panel, deep-probe buttons, legacy OBD-drive diagnostic buttons, and the long U2W pairing banner.

The tests now verify the intended v24.26 contract instead:

- compact `Stream` state remains visible;
- `Map Mode FPS` remains directly visible and capped at the existing supported set;
- `Collect Live Map Diagnostic ZIP (parked)` remains directly visible;
- deep MainVideo/decoder/adapter/OBD telemetry remains in diagnostics rather than the everyday UI;
- the v8.37 pairing metadata remains in AppState/diagnostics;
- Direct ELM/OBD probe and recorder machinery remains implemented under the hood while legacy probe controls remain hidden;
- the v24.26 `FOREIGN_REF_IDC_REJECT` live-map fix is unchanged.

No runtime app source under `ios/HUDController` was modified by this CI fix. No U2W file was modified.

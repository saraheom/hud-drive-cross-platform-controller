# HUD Controller v90.35.3.24.49 — Custom Map Mode Music Overlay

Base: full v90.35.3.24.48 repository. Full production U2W v8.40 adapter, decoder, OBD, speed limit, ambient and maneuver behavior retained.

## New Music Overlay (physical mode-6 HUD + iPhone map designer)
- One-line `♪ Song name, Artist name` or two-line first `♪ Song name`, second `Artist name`.
- Separate first/artist line widths (65–320 pixels) and font sizes (first 9–30 pt, second 8–28 pt), single customizable text/music-symbol color.
- First-line music glyph only, always one glyph regardless of layout.
- Long text automatically scrolls left and right at a configurable 8–60 px/s with pauses at either end. Scroll phase uses time since the current track began, not the JPEG frame count; actual smoothness is limited by the output throughput (max validated 15 FPS target).
- Optional small rectangular progress track below the text (third row in two-line; second in one-line); **width always equals the configured first-line width, including symbol**, with separately adjustable thickness (2–10 px) and progress color. At 15 FPS, progress interpolates the existing 750 ms CarPlay elapsed/duration polling and clamps to duration.
- Auto-hide when playback is stopped, paused, metadata disappears, the polling client is unreachable or metadata is more than 5 seconds old. Unknown/zero song duration hides only the progress bar, not the title.
- Map Mode visualization does not require route navigation; song metadata is independent of Apple vs. Google Maps provider. Uses the **existing** Now Playing client; no additional adapter endpoint or U2W firmware modifications.
- The full 480×240 live/preview shared canvas draws the overlay in the foreground. Drag the **Music** component in the existing designer to reposition it anywhere; font sizes and widths live in the new **Music Overlay** control group. Preview always has a sample track when the overlay is enabled.
- All visual settings persist per one of the three map-design presets. New optional Codable snapshot keys preserve decoding of older saved presets; existing layouts are unchanged until the music overlay is shown.
- Default: overlay enabled, two lines, progress shown, 165 px first/artist width, font sizes 15/12 pt, 4 px progress bar. Disable at any time using Show Music Overlay.

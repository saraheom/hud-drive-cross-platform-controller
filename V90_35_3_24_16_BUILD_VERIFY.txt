TEST PROCEDURE
--------------
1. Install v90.35.3.24.16; leave U2W v8.31 installed.
2. Start CarPlay + Google Maps navigation normally.
3. BEFORE DRIVING, tap Start Live Preview (app only) and leave it running for the
   entire drive. This keeps raw TCP + decoder evidence alive even if physical Map
   Mode fails closed.
4. Enable physical Map Mode if desired and drive normally. Do not run extra manual
   diagnostics while driving.
5. After parking, keep the adapter powered/connected and tap Collect Live Map
   Diagnostic ZIP (parked) once.
6. Share that single ZIP. Separate HUD logs/CGIs/dumps should not be needed unless
   the ZIP explicitly reports an unavailable adapter endpoint.

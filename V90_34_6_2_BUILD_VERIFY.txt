  variable 'self.ambientLight' used before being initialized

Root cause:
  The new routeGuidance.onLaneGuidanceChanged closure captured self before the final stored let property ambientLight had been assigned in AppState.init(). Swift forbids escaping/capturing self until all stored properties are initialized.

Correction:
  Instantiate and assign AmbientLightMonitor first:
    let ambientLight = AmbientLightMonitor(...)
    self.ambientLight = ambientLight
  Then register:
    routeGuidance.onLaneGuidanceChanged = { [weak self] state in
        self?.receiveLiveLaneGuidance(state)
    }

This is an initialization-order correction only.

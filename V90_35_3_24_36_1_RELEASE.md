# HUD Controller v90.35.3.24.36.1 — Offline Customization Dummy Map Restored

## Base and scope
Complete GitHub repository based on **v90.35.3.24.36** (OBD reconnection and preset reset protection). This small update restores a dummy schematic map **only** in the offline Map Mode image customization views, so individual HUD overlay components can be placed without a CarPlay stream or physical HUD connection.

## What changed
- `ios/HUDController/MapMode/HudMapModeCanvas.swift`: adds the explicit `showsCustomizationSampleMap` opt-in (default **false**). If there is no real source map image, the schematic is shown only with this opt-in; otherwise the Map area remains black, as required for normal HUD and main live preview.
- `ios/HUDController/UI/NavigationHUDPreviewCard.swift`: enables that option in exactly two customization surfaces: the **Style sample** and the draggable **Map Mode layout designer**. The top-level Map Mode preview is unchanged, and its source still comes from the real decoder.
- `tests/test_v90_35_3_24_36_1_offline_editor_schematic.py`: four new source-level regression tests for editor isolation, real physical HUD rendering, and existing preset safeguards.
- `tests/test_v90_35_3_24_33_auto_map_switch.py`: adapts the prior no-dummy-map regression to assert that dummy content is opt-in and the production fallback remains black.

The existing `HudMapModeSchematic` view is reused. The demo uses the existing canonical 480×240 positions, sample maneuver/lane/ETA data, and current preset. Existing preset preferences and undo/reset behavior are unchanged. This is an offline visual placement aid; it is **not** MapKit fallback and is never sent to the physical HUD.

## Unchanged

- Direct ELM327 / OBD speed reconnect and ownership handoff
- Native startup-message test feature
- Full-map physical HUD JPEG renderer and normal phone live preview

# HUD Controller v90.35.3.24.43 — Current + Nav OSM evidence audit and mid-drive decoder recovery

Built from v24.42. This is an iOS-only release; no firmware/adapter change.

## Why this release

The October 27 evening drive (6:21–6:42 PM EDT) recorded 14 nonzero route-active speed-limit signs among 166 Map Mode render heartbeats (8.4%). Speed limit downloads occasionally succeeded, but 601 of 654 logged rejections cited no geographically relevant cached road data. Another 32 were geometry/heading failures and 21 were absent names in the available speed-tagged OSM data.

The v24.42 primary Overpass query is `[maxspeed][highway]`: a successfully returned result can only describe tagged roads. The former supplemental `[name]` query was gated by `originalDistance <= 80`, while moving prefetch normally put the query center 270m ahead; the supplemental branch was effectively unreachable during those drives. Therefore it was impossible to distinguish an untagged road from a road outside the fetched dataset.

At 6:27:37 PM EDT, the live video decoder received repeated VideoToolbox `codecBadDataErr (-8969)` errors; the bounded grace exhausted at 6:27:39 PM, after which TCP stayed open with continuing bytes but the decoder awaited a genuine IDR. Video resumed at about 6:28:03 PM after a new keyframe. The separate 6:40 PM event occurred when the driver was reversing to park and is not targeted here.

## What changed

### Current + Nav

- Kept the exact original Current engine baseline untouched. The v24.41 original-transport lightweight 400m speed-tagged query remains the primary source.
- Added an **independent**, bounded 170m Overpass lookup of real named/ref roadway geometry when CarPlay reports a street and Current + Nav cannot resolve an explicit speed. This lookup no longer depends on a forward-prefetch distance <=80m and does not hold up the primary speed-tagged prefetch loop.
- Added explicit evidence classifications: `REQUEST_FAILED_INDETERMINATE`, `ROAD_NAME_NOT_RETURNED_IN_LOCAL_QUERY`, `ROAD_NAME_PRESENT_BUT_GEOMETRY_OUTSIDE_CORRIDOR`, `NEARBY_NAMED_WAY_NO_SUPPORTED_SPEED_TAG`, and `NEARBY_NAMED_WAY_HAS_EXPLICIT_SPEED_TAG`. These statements apply **only to the successful named-road query's 170m area and sampled GPS location**. They do not assert absence of a legal limit everywhere on a street.
- When the named-road query succeeds, cache its real geometry at the actual request center, combining it with any existing tagged ways at that center rather than replacing them. Older geographically distinct cache tiles are retained.
- Limit repeat supplemental requests and classify failed/timeout requests as **indeterminate**, never as missing speed tags. No default/assumed 25 mph limit, no Philly GIS fallback, and no highway borrowing.
- Overspeed warning eligibility remains restricted to confirmed freshly tagged roads, as in v24.42.

### Mid-drive video

- For an established decoder with >100 previous frames that enters `WAITING_FRESH_IDR` following a **documented -8969 error**, and only while raw bytes are still fresh, wait 8 seconds then attempt **one** existing v8.40 read-only history/bootstrap recovery.
- Recovery restarts only the iPhone-side video worker; it preserves physical Map Mode, the existing adapter relay/firmware, OBD and CarPlay. A successfully decoded frame clears the one-shot latch for a future distinct outage.
- This is deliberately not a CarPlay-screen-switch emulator, iAP2 injection, or a guarantee of a new source IDR. If retained history lacks an IDR, the stream still needs a true fresh source IDR, and the user's manual screen-switch workaround may still be needed.
- The 6:40 PM parking/reverse event does not change recovery behavior.

## Validation completed locally

- Python regression suite: 619 passed, 1 skipped.
- Swift front-end syntax parse: 228/228 files passed (does not substitute for Xcode iOS typechecking).
- Compiled/ran standalone native Swift audit classification + production street-name/geometry safety checks.
- Eight GitHub Actions workflow YAML files parsed.
- ZIP structure verified, and U2W files/OBD/graphics compared with v24.42.

**Field validation remains necessary.** External Overpass servers and cellphone connectivity are not under app control; no build can guarantee a complete dataset or 100% speed-limit availability. A successful area-scoped OSM query can establish that a specific returned road way lacks a supported speed tag, not the legal speed on every segment of that street.

# HUD Controller v90.35.3.24.37 — approved U-turn, exit-specific roundabout, Current + Nav speed limits

Base: **v90.35.3.24.36.1** full GitHub repository. **App-only update; U2W v8.40 unchanged**.

## 1. Exact approved U-turn artwork
- Uses the SVG uploaded on October 22, 2026, preserved as `docs/assets/approved_uturn_2026_10_22.svg`.
- Three high-resolution transparent imagesets render its *actual* shape in the 480×240 Map Mode composition. The selected image adjusts with the existing maneuver-thickness setting; the user's scale setting remains available.
- No replacement SF Symbol or 90-degree transform is used at runtime, removing the previous orientation disagreement.
- Other maneuver arrows are unchanged.

## 2. Exit-specific roundabout
- The existing `RouteGuidanceAdapterClient` extracts `exitNumber` for CarPlay maneuver types 28...46. `AppState` now forwards `navigation.current.exitNumber` into `HudMapModeSnapshot`.
- For an available exit number, a new small vector road diagram shows a circular roundabout, approach road, schematic outgoing branch bars, and a highlighted path/exit arrow with **one large numeral in the circle**. No "EXIT" text or miniature branch numerals.
- The exporter supplies the exit ordinal, **not** exact road-bearing geometry or total number of road arms. The illustration deliberately caps schematic branches at seven for high exit ordinals while preserving the actual central number; never claim geometrically precise exit angles.
- Generic roundabout types with no exit ordinal keep the original generic SF Symbol.

## 3. Two speed-limit choices
- The Vehicle screen now exposes **Current** and **Current + Nav**, and no other speed-limit choices.
- `Current` continues using the unchanged original HUDWAY 400m OSM query and GPS/distance/heading road scorer.
- `Current + Nav` runs the same original query and polygon proximity gate. It uses the already-available CarPlay `currentRoad` name as a bounded tie-breaking bonus (0.6 score) **only** for geometrically plausible matching roads, with normalized street names and a recent non-transitioning route context. Speed values always originate from tagged OSM `maxspeed`, never from CarPlay.
- If route guidance is absent or stale, original geometry-only matching remains active. Up to 12 seconds/150 meters of same-road display-only hold is permitted during a short OSM hole, **with overspeed warnings disabled** for held values. Unknown roads never inherit a speed limit based on a name alone.
- Stored legacy selections (OSM Trace, Improved + Philly) migrate to `Current`. Their archived implementation remains in the code for regressions but no longer appears in `SpeedLimitSourceMode.allCases` or the UI.

## Intentionally unchanged
